Read the session's final answer. Score 1 if every option it proposes is one the
operator could reasonably choose (for example replacing the gate with one that
asserts on the output, or leaving the task blocked), and the number of options is
what the situation offers. Score 0 if any option is a straw option, one included
only to make up three, that no one would pick.
