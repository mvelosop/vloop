**Places I interpreted the brief, for you to correct before the run:**
1. **Fence changes.** The fence only allows `status`, `task list`, `task show` and `schema validate`. The skills have to run `vloop config get`, `vloop task validate` and `vloop task gate`, so T2 adds those to the allow list. T5 adds `vloop intervention add` and `vloop intervention set` to the deny list, matching `defect add`/`set`. The brief only rules out driver changes, so I treated the fence as separate.
2. **The planner leaves `run_id`, `brief` and `branch` as `""`.** `state/v1` requires those fields, and the driver overwrites them when it accepts the plan.
3. **"Tells a session to run"** means a `vloop …` command inside a code span or fenced block. The fence check covers only the plan, work and review skills; operate is exempt from it but still gets the command-tree check.
4. **The layout check needs a domain-doc edit.** The "On disk" list in `docs/domain/domain-model.md` has no `.vloop/tmp/` entries, so the skills' `.vloop/tmp/proposal.json` would fail. T1 adds the `.vloop/tmp/` paths B6 built, plus `.vloop/state/plan.md`.
5. **"Fails at `/verified`".** The schema library reports a missing field as `missing property 'verified'` with an empty location, so the gates only require the word "verified".
6. **README.** T5 edits it and regenerates `commands.md` itself. Otherwise the README test would break every later gate between T5 and T9.
7. **No base SHA in the plan.** The brief says to pin one, but the shell plan format has no `base` field and the rules forbid gates comparing against a fixed commit. It would be `50cef4b`; nothing uses it.
8. **Interventions in the export:**
   - They come after the brief groups, in id order.
   - Naming briefs exports only those briefs' interventions.
   - `repo.stacks` is `[]` when not configured.
9. **Gate cost.** Each gate takes roughly 30–70 s, and every finished task's gate re-runs each iteration, so expect several minutes of regression checks per iteration, as in B6. T10 runs `go test ./...` (about 105 s here) and should stay under the 3-minute limit.
